# 今日市场提示

## 接入与文件

- 首页入口：`frontend/src/views/Home.vue`，桌面端采用独立右栏展示提示卡，左侧行情概览下方紧接行业板块，避免提示内容撑高行情卡；下方七类榜单保留全宽。1200px 以下按行情概览、市场提示、行业板块顺序纵向排列，720px 以下行情卡片单列。
- 卡片及展开详情：`frontend/src/components/DailyMarketIntelligenceCard.vue`；格式化及过期判断：`composables/marketIntelligence.js`。
- 中英文文案：`i18n/dailyMarket.zh-CN.js`、`dailyMarket.en.js`，由原语言包导入。
- API：`GET /api/market-intelligence`，只使用登录用户 ID，客户端不能指定他人 ID。返回 `status / refreshing / report / errorCode`。
- 编排：`DailyMarketIntelligenceServiceImpl`；公式：`MarketSnapshotCalculator`、`PortfolioSnapshotCalculator`；判断：`DailyMarketAnalyzer`、`MarketResearchRules`；可调阈值：`MarketIntelligenceConstants`。
- `MarketIntelligenceScheduledTask` 在上海时间工作日 15:05 至 15:55 每十分钟尝试归档收盘快照，数据源交易日历再次验证交易日。无需用户保持在线。最多保留 120 个交易日。

## 数据源与边界

1. `akshare_market_activity.py` 复用新浪沪深京全市场报价，一次获取广度、成交额和用户持仓所需最新价/昨收价。股票代码去重、剔除非 A 股；广度排除无有效交易报价的停牌等记录；成交额对同范围原始金额求和，任一金额无效时总额为空。人民币元，不混入原首页仅沪深的历史序列。
2. 涨跌停统计为东方财富完整沪深股池，非首页前 20 条。连板高度使用涨停股池连板数最大值；炸板率为炸板池股票数 / 涨停与炸板池代码并集数，失败时独立留空。与沪深京广度的范围差异明确标注。
3. `akshare_index.py --count 130` 获取上证、沪深 300、中证 500、中证 1000；先截止目标日期再取历史。盘中剔除未完成交易日计算均线、方向和阶段结构。
4. 持仓来自 `PortfolioHoldingDao.selectByUserId`；行业通过 `StockBasicDao.selectByTsCodeIn` 一次批量查询。全市场报价只存内部研究缓存，不广播给浏览器。
5. 行情源没有逐笔时间，交易日期由交易日历及采集时间推定，因此不能保证逐笔同步。持仓与广度共用快照，指数单独采集；不同日期不做基准比较。报告保留采集时间、交易日期、范围和局限。
6. 首次部署不回填伪历史。连续同口径收盘样本不足时，5 / 20 日比较为空；周期提示“暂不充分”。归档缺任一交易日会截断比较窗口。Redis 历史需要随项目 Redis 一起持久化/备份。

## 公式

- 成交额变化 = `(当前完整日成交额 / 对照成交额 - 1) × 100%`。对照为前交易日或之前连续 5 / 20 日均值；盘中不计算这些比较。
- 上涨/下跌占比 = 对应家数 / `(上涨 + 下跌 + 平盘)`；涨跌比 = 上涨 / 下跌，零分母留空；广度净值 = 上涨 - 下跌。相对历史占比变化用百分点。
- MA20/60/120 为完整收盘价算术均值；方向使用与五个交易日前均线的百分比变化；阶段高低点比较相邻两个 20 日窗口的最高价/最低价。
- 持仓市值 = `Σ数量 × 最新价`；总成本 = `Σ数量 × 成本价`；浮盈 = 市值 - 总成本；浮盈率 = 浮盈 / 总成本。
- 当日持仓盈亏 = `Σ数量 × (最新价 - 昨收)`；当日收益率 = 当日盈亏 / `Σ数量 × 昨收`。数量固定为当前持仓，不含现金、成交流水、部分卖出、已实现盈亏、分红或费用，不能称为账户收益率。
- 相对收益 = 当日持仓收益率 - 同日沪深 300 涨跌幅，以百分点展示。持仓浮盈率不是风险收益比。
- 集中度为最大单股/行业市值占比，同股跨账户合并。任一持仓报价缺失时，组合市值/收益留空，保留可用明细；行业缺失时行业集中度留空。零成本不产生无穷收益率。

## 判断规则

- 日内上涨占比 ≥60% 偏强，≤35% 偏弱，其余震荡；这不是中期牛熊结论。
- 周期至少需要三个指数覆盖 120 日均线及五日前均线，并有连续 20 日广度、同日指数。均线多头/空头、全部方向和阶段高低点一致才给趋势标签。60 日均线转弱识别熊市风险；120 日均线上方但结构不完整识别牛市分化。广度中期减弱或持续缩量将完整多头判断降为分化。
- 情绪结合广度、涨跌停结构和同日指数涨跌；过热还要求完整日成交额超过 20 日均值至少 10%。缺数据不强行认定中性。情绪不重复计入独立风险组。
- 风险组：中期趋势转弱、广度偏弱、下跌放量/持续收缩、组合集中/显著落后。下跌放量要求沪深 300 下跌且成交额增幅至少 10%；持续收缩要求连续五个样本递减且当前额低于 5 / 20 日均值至少 10%。
- 个股集中阈值 30%、行业 50%；相对沪深 300 日收益差 ±1 个百分点区分强弱。
- 至少三组风险且含广度恶化 → 高；至少两组 → 较高；无风险组且牛市趋势、广度强、无过热、组合风险可判断 → 低；其余中。缺关键报价、日期不齐、过期 → 信息不足。
- 缺宏观、政策、财报及估值证据时不编造，置信度最多中；历史/必要指标不足降为低。每次附支持证据、反向证据及确认/推翻条件。
- 行动为条件式思路，优先处理数据不足、多组风险、组合暴露；不因亏损建议无条件持有，也不产生全仓卖出指令。
- AI 只从经验证的信号代码中选择排序 3–5 项，不能改变数字、分类或增加事实。输出不合法、模型不可用或超过二十秒则保留确定性摘要。

## 刷新与异常

市场与用户报告各缓存五分钟；用户报告互相隔离。接口即时返回，采集和模型调用使用虚拟线程。前端初次加载每五秒轮询，之后每三十秒读取缓存；请求退出时取消。刷新失败保留旧报告并标记，失败后三十秒可重试。采集超过十五分钟或未来时间戳时前端与后端均降级；过期卡片不展示确定风险/行动。

已有运行中的 Java 进程需重启后加载新 Controller/Service；前端开发服务器可热更新。无需新增数据库表。
